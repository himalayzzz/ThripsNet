# Demo assets

Purpose
-------
This folder contains images, short videos and presentation media used to demonstrate ThripsNet features (example leaf photos, screenshots, demo recordings). These assets are intended for UI demos, documentation and model examples — not as training data.

Contents
--------
- `images/` — annotated sample leaf photos used in UI demos.
- `videos/` — short demo recordings showing app flows and alerts.
- `slides/` — presentation slides and screenshots.

Usage notes
-----------
- Do not use these files as a training dataset unless they are explicitly labeled and versioned in `dataset/`.
- Keep demo assets small and representative for faster builds and smaller repository size.

If you want additional demo material, add a small README inside subfolders describing provenance and license for each file.
